**Status (October 28, 2026):** The private [`pets-model` service](https://pets-model-850678646784.us-east1.run.app) is ready in `mdi-yimingwu-pets` (`us-east1`). It uses `gemini-3.5-flash-lite` through `pets-model-runtime@mdi-yimingwu-pets.iam.gserviceaccount.com`. Direct IAP is enabled; an unauthenticated request redirects to Google sign-in, and `kh1399@georgetown.edu` opened the site. Two small live questions returned Gemini answers with public citations. Minimum instances are zero, the service and revision maximums are one, and concurrency is one.

Cloud Run serves the page and same-origin `/api/chat` endpoint. The server calls project-scoped Vertex AI using its [Cloud Run service identity](https://docs.cloud.google.com/run/docs/securing/service-identity), which has a custom role containing only `aiplatform.endpoints.predict`. This route does not use a Gemini API key; the previously mentioned GitHub Environment secret is not part of it. The runtime environment contains `VERTEX_PROJECT_ID=mdi-yimingwu-pets`, `VERTEX_LOCATION=global`, and `GEMINI_MODEL=gemini-3.5-flash-lite`.

## Cost and privacy

The Georgetown Cloud Console shows an alerts-only `pets-total-500` budget scoped to `mdi-yimingwu-pets` from October 1, 2026 with no end date. It also shows **configured** monthly spend caps of $450 for Vertex AI and $50 for Cloud Run. [Spend caps are service-specific and reset each month](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps); Cloud Build, Artifact Registry, and storage are outside those two caps. The billing report displayed **$0.00** for October 1–28 when checked, rounded to cents and subject to reporting delay. The ignored local cost CSV records tests and deployments separately from Billing.

[Cloud Run has a free allowance](https://cloud.google.com/run/pricing), and [Gemini has separate token pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing). The app limits valid chat requests to 30 per 10 minutes and paid model calls to 20 per UTC day **per process**. Counters reset on restart and can duplicate if revisions overlap. A maximum-instance setting can also be briefly exceeded. These controls are not a hard $500 lifetime cap. The server logs model name and token counts without chat text, so compare those logs and actual Billing reports during the trial.

The app retrieves original summaries of public PET sources. When Gemini is active, chat text and case details pass through Cloud Run to Vertex AI. Ask visitors to use hypothetical details and avoid protected student records or confidential partner information.
