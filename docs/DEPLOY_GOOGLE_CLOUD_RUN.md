## Cost and privacy

[Cloud Run has a free allowance](https://cloud.google.com/run/pricing), and [Gemini has separate token pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing). The app limits valid chat requests to 30 per 10 minutes and paid model calls to 20 per UTC day **per process**. Counters reset on restart and can duplicate if revisions overlap. A maximum-instance setting can also be briefly exceeded. These controls are not a hard $500 cap. The server logs model name and token counts without chat text, so compare those logs and actual Billing reports during the trial. A checkout-local, ignored CSV records deployment and test events; it is not a billing ledger.

The app retrieves original summaries of public PET sources. When Gemini is active, chat text and case details pass through Cloud Run to Vertex AI. Ask visitors to use hypothetical details and avoid protected student records or confidential partner information. See the [privacy boundary](../README.md#privacy-boundary), [content policy](CONTENT_POLICY.md), and [source audit](SOURCE_AUDIT.md).
