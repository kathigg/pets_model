# Deploy PETs Model to Google Cloud Run

**Status (November 3, 2026):** The private [`pets-model` service](https://pets-model-850678646784.us-east1.run.app) is ready in `mdi-yimingwu-pets` (`us-east1`), revision `pets-model-00014-v6s`. It uses `gemini-3.5-flash` through `pets-model-runtime@mdi-yimingwu-pets.iam.gserviceaccount.com`. Direct IAP remains enabled and the IAP service agent is the sole Cloud Run Invoker. This revision asks one follow-up at a time and remembers the active question across browser reloads; 65 automated checks and 15 retrieval evaluations passed. Minimum instances are zero; maximum instances and concurrency are one. The revision contains no NYSED notes or private retrieval integration.

The deployment CLI warned that it could not change the service IAM policy. A read after deployment confirmed the policy still grants `roles/run.invoker` only to the IAP service agent, with no `allUsers` grant. The account still cannot inspect the separate IAP visitor policy.

Cloud Run serves the page and same-origin `/api/chat` endpoint. The server calls project-scoped Vertex AI using its [Cloud Run service identity](https://docs.cloud.google.com/run/docs/securing/service-identity), which has a custom role containing only `aiplatform.endpoints.predict`. This route does not use a Gemini API key; the previously mentioned GitHub Environment secret is not part of it. The runtime environment contains `VERTEX_PROJECT_ID=mdi-yimingwu-pets`, `VERTEX_LOCATION=global`, `GEMINI_MODEL=gemini-3.5-flash`, and `BILLING_APP_LABEL=kathleen-chatbot`. `BILLING_APP_LABEL` adds the request label `app=kathleen-chatbot` to each Vertex AI call, so Cloud Billing can split this app's Gemini cost from other work in the same project. It must be 1 to 63 lowercase letters, digits, underscores, or dashes, or the server refuses to start. An empty value turns the label off. A revision deployed before the billing label code was added ignores it without an error, so redeploy the code, not only the variable. Set it with `gcloud run services update pets-model --region us-east1 --project mdi-yimingwu-pets --update-env-vars BILLING_APP_LABEL=kathleen-chatbot`. Confidential NYSED notes remain local and are not used by the hosted app.

## Cost and privacy

The Georgetown Cloud Console previously showed an alerts-only `pets-total-500` budget scoped to `mdi-yimingwu-pets` from October 1, 2026 with no end date. That period does not match the updated $500 monthly target. It also showed **configured** monthly spend caps of $450 for Vertex AI and $50 for Cloud Run. [Spend caps are service-specific and reset each month](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps); Cloud Build, Artifact Registry, and Secret Manager are outside those two caps. The ignored local cost CSV records tests and deployments separately from Billing.

[Cloud Run has a free allowance](https://cloud.google.com/run/pricing), and [Gemini has separate token pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing). The app limits valid chat requests to 60 per 10 minutes and paid model calls to 250 per UTC day **per process**. Counters reset on restart and can duplicate if revisions overlap. A maximum-instance setting can also be briefly exceeded. These controls are not a hard $500 monthly cap. The two November 3 live Gemini 3.5 Flash checks used 709 and 814 total tokens; estimated combined token charges at the listed global rates were about $0.008, with actual billing pending. The server logs model name and token counts without chat text, so compare those logs and actual Billing reports during the trial.

The app retrieves original summaries of public PET sources. When Gemini is active, chat text and case details pass through Cloud Run to Vertex AI. Ask visitors to use hypothetical details and avoid protected student records or confidential partner information.
