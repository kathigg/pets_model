# Deploy PETs Model to Google Cloud Run

## Cloud Shell when the local CLI login fails

From the Google Cloud Console for `mdi-yimingwu-pets`, open Cloud Shell and authorize it. Cloud Shell already includes `gcloud`, so no API key or local CLI login is needed. For a future code deployment, run these commands **once** from the Cloud Shell home directory:

```bash
cd ~
if [ -d pets_model/.git ]; then git -C pets_model pull --ff-only; else git clone https://github.com/kathigg/pets_model.git pets_model; fi
cd pets_model
bash scripts/deploy-cloud-run.sh
```

The script deploys the checked-out GitHub commit to the existing private `pets-model` service, selects `gemini-3.8-flash`, and keeps the dedicated runtime identity, zero minimum instances, one maximum instance, up to four concurrent requests, and no unauthenticated access. It does not change the IAP visitor policy. Source deployment starts one Cloud Build job and can incur charges. After it finishes, check the printed ready revision and test a public web question such as “Can you explain what sythetic data is?” The server uses Vertex AI Google Search grounding and returns only metadata-supported text and web links. The web path uses Gemini's low thinking level to reduce waiting time. Cloud Shell may ask you to authorize its Google Cloud access when it first starts.

## Cost and privacy

The Georgetown Cloud Console previously showed an alerts-only `pets-total-500` budget scoped to `mdi-yimingwu-pets` from October 1, 2026 with no end date. That period does not match the updated $500 monthly target. It also showed **configured** monthly spend caps of $450 for Vertex AI and $50 for Cloud Run. [Spend caps are service-specific and reset each month](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps); Cloud Build, Artifact Registry, and Secret Manager are outside those two caps. The ignored local cost CSV records tests and deployments separately from Billing.

[Cloud Run has a free allowance](https://cloud.google.com/run/pricing), and [Gemini has separate token pricing](https://cloud.google.com/model-garden/pricing). The app limits valid chat requests to 60 per 10 minutes and paid model calls to 250 per UTC day **per process**. Counters reset on restart and can duplicate if revisions overlap. A maximum-instance setting can also be briefly exceeded. These controls are not a hard $500 monthly cap. The two November 3 live Gemini 3.5 Flash checks used 709 and 814 total tokens; estimated combined token charges at the listed global rates were about $0.008. The November 13 feedback checks used seven Gemini calls, estimated at about $0.0442. The November 14 MDI case-card live checks used five Gemini calls (6,149 input, 663 response, and 2,551 reasoning tokens), estimated at about $0.0381 using the listed global rates. These are estimates, not actual billed amounts. Cloud Build and Cloud Run charges for the test deployments are still pending. The server logs model name and token counts without chat text, so compare those logs and actual Billing reports during the trial.

The app retrieves original summaries of public PET sources. When Gemini is active, chat text and case details pass through Cloud Run to Vertex AI. Ask visitors to use hypothetical details and avoid protected student records or confidential partner information.
