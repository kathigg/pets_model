**General citation rule.** Other corpus headings also describe our note rather than reproduce the original page heading. Inline citations now identify the issuing organization or the public report page; the expanded evidence panel separates **our note**, **our summary**, any verified source excerpt, and the original-page link. Definition routing now requires a source passage tagged for a direct definition. For example, NIST and ICO definition passages can answer covered terms locally; a pilot or risk note alone is not treated as a direct definition. Unsupported definitions still route to public web grounding.
